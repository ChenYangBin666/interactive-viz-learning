什么是卷积

卷积是 CNN 的核心操作：用一个小的卷积核（kernel）在输入数据上滑动，在每个位置做逐元素相乘再求和，得到输出特征图的一个值。与全连接层不同，卷积层利用局部连接和权重共享，大幅减少参数量，同时保留空间结构信息。

步幅与填充

步幅（Stride）控制卷积核每次移动的距离；填充（Padding）在输入外围补零，控制输出大小。它们共同决定了输出特征图的尺寸：

4 x 4

步幅 (Stride)

  • stride=1：逐像素滑动，输出最大
  • stride=2：每次跳两步，输出约为原来的一半
  • stride=3：更激进的下采样

填充 (Padding)

  • padding=0（valid）：不填充，输出缩小
  • padding=1（same for 3x3）：输出与输入同大小
  • padding=2：输出可大于输入
ⓘ stride=1 保留更多空间信息；stride=2 可将特征图尺寸减半，常用于下采样。当 padding = (K-1)/2 且 stride=1 时，输出与输入大小相同，称为 "same" 填充。
3

多通道卷积

真实图像有多个通道（如 RGB 三通道）。多通道卷积核的深度与输入通道数相同，每个通道分别卷积后求和，再加偏置，得到输出的一个通道。

输出通道 $k$: $\quad Y_k[i,j] = \sum_{c=1}^{C_{in}} (X_c * W_{k,c})[i,j] + b_k$

其中 $C_{in}$ 是输入通道数，$W_{k,c}$ 是第 $k$ 个卷积核在第 $c$ 个通道的权重。若有 $C_{out}$ 个卷积核，则输出有 $C_{out}$ 个通道。

本节小结

卷积运算

卷积核在输入上滑动，每个位置做逐元素乘法再求和。核的大小决定了感受野，核的权重决定了提取什么特征。

步幅与填充

步幅控制滑动步长，影响下采样倍率。填充在边界补零，保持空间分辨率。两者共同决定输出尺寸。

多通道机制

输入有 C 个通道时，卷积核也有 C 层。各通道分别卷积后求和，N 个卷积核产生 N 个输出通道。

特征提取

不同卷积核检测不同模式：边缘、模糊、锐化等。CNN 通过训练自动学习最优的卷积核权重。
