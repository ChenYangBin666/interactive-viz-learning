LSTM 预测

长短期记忆网络（LSTM）通过门控机制解决传统 RNN 的梯度消失问题。遗忘门决定丢弃哪些信息，输入门决定更新哪些新信息，输出门决定输出什么。细胞状态如同传送带，信息可以无损地沿时间线传递。

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$$ $$\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C) \quad C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$ $$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad h_t = o_t \odot \tanh(C_t)$$

Temporal CNN

时序卷积网络（TCN）使用一维因果卷积处理时间序列。不同大小的卷积核捕捉不同尺度的模式——小核捕捉短期波动，大核捕捉趋势。空洞卷积（Dilated Convolution）通过指数增长的间隔，以较少参数获得超大感受野。

$$y_t = \sum_{k=0}^{K-1} w_k \cdot x_{t - d \cdot k} \quad \text{感受野} = 1 + \sum_{l=1}^{L} (K-1) \cdot d_l$$

Transformer 预测

Transformer 通过自注意力机制直接建模序列中任意两个时间步之间的依赖关系，无需像 RNN 那样逐步传递信息。多头注意力让模型同时关注不同维度的模式——有的头关注短期动量，有的头关注长期趋势。

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V \quad \text{MultiHead} = \text{Concat}(\text{head}_1,...,\text{head}_h)W^O$$

序列到序列

编码器-解码器架构将历史序列编码为上下文向量，再逐步解码出未来预测。预测步数越多，误差累积越严重——这就是多步预测退化问题。实际应用中通常限制预测步数或使用 teacher forcing 技术。

$$\text{Encoder: } h_T = f_{\text{enc}}(x_1, ..., x_T) \quad \text{Decoder: } \hat{y}_{T+k} = f_{\text{dec}}(h_T, \hat{y}_{T+1}, ..., \hat{y}_{T+k-1})$$
