04 - GCN: 图卷积网络

Graph Convolutional Network -- 从频谱滤波到节点分类的完整链路

~

1. 频谱直觉 -- 平滑效应

Spectral Intuition

GCN 的核心操作是用归一化邻接矩阵 $\hat{A}_{norm}$ 对特征做聚合。从频谱角度看，这等价于一个低通滤波器：每叠加一层，高频信号被抑制，节点特征趋于一致。当层数过深时，所有节点特征收敛到同一值 -- 这就是过度平滑（Over-smoothing）问题。

核心公式: 反复乘以 $\hat{A}_{norm} = \hat{D}^{-1/2}\hat{A}\hat{D}^{-1/2}$ 相当于在图上做低通滤波。$k$ 层 GCN 后特征为 $H^{(k)} = \hat{A}_{norm}^k H^{(0)} W$，频谱能量集中到最低频分量。

热 -- 节点特征值

拖动滑块观察：随着层数增加，节点颜色趋于一致，方差逐层下降。

$$H^{(k+1)} = \hat{A}_{norm}\, H^{(k)} \quad \Rightarrow \quad \text{Var}(H^{(k)}) \to 0 \;\text{ as }\; k \to \infty$$

这意味着 GCN 的深度受限 -- 通常 2-3 层效果最佳。更深的网络需要残差连接、DropEdge 等技巧来缓解过度平滑。

2. 归一化对比

Normalization Comparison

为什么不直接用 $AH$？因为邻接矩阵中高度数节点的行之和远大于低度数节点，特征尺度会严重失衡。三种归一化策略各有特点：

无归一化

$AH$ -- 高度数节点主导

Hub 节点的聚合值是叶子节点的数倍

对称归一化

$D^{-1/2}AD^{-1/2}H$ -- 均衡

源与目标的度数共同缩放，最常用

随机游走归一化

$D^{-1}AH$ -- 行随机

每行之和为 1，等价于邻居均值

$$\text{无归一化: } (AH)_i = \sum_{j \in \mathcal{N}(i)} h_j \qquad \text{对称: } (\hat{A}_{sym}H)_i = \sum_{j} \frac{A_{ij}}{\sqrt{d_i d_j}} h_j \qquad \text{随机游走: } (\hat{A}_{rw}H)_i = \frac{1}{d_i}\sum_{j \in \mathcal{N}(i)} h_j$$

GCN 原论文 (Kipf & Welling, 2017) 选择对称归一化 $\hat{D}^{-1/2}\hat{A}\hat{D}^{-1/2}$ 并加上自环，是因为该形式对应图拉普拉斯的一阶切比雪夫近似。

两层 GCN 前向传播公式

$$\hat{A} = A + I_N \qquad \hat{D}_{ii} = \sum_j \hat{A}_{ij}$$

$$H^{(1)} = \text{ReLU}\!\left(\hat{D}^{-1/2}\hat{A}\hat{D}^{-1/2}\, H^{(0)}\, W^{(0)}\right)$$

$$H^{(2)} = \text{softmax}\!\left(\hat{D}^{-1/2}\hat{A}\hat{D}^{-1/2}\, H^{(1)}\, W^{(1)}\right)$$

其中 $H^{(0)} \in \mathbb{R}^{N \times F}$ 是初始特征，$W^{(0)} \in \mathbb{R}^{F \times H}$ 和 $W^{(1)} \in \mathbb{R}^{H \times C}$ 是可学习权重，$C$ 为类别数。

4. 自环的意义

Self-Loop Significance

GCN 的关键设计之一：在邻接矩阵中添加自环 $\hat{A} = A + I$。没有自环时，节点聚合只包含邻居的特征，自身信息在传播中丢失。加上自环后，节点将自己视为自身的邻居，从而保留原始特征。

数学解释

$$\text{无自环: } h_v^{(l+1)} = \sigma\!\left(\sum_{u \in \mathcal{N}(v)} \frac{1}{c_{vu}} h_u^{(l)} W^{(l)}\right) \quad \text{--- 不包含 } h_v^{(l)}$$

$$\text{有自环: } h_v^{(l+1)} = \sigma\!\left(\sum_{u \in \mathcal{N}(v) \cup \{v\}} \frac{1}{\hat{c}_{vu}} h_u^{(l)} W^{(l)}\right) \quad \text{--- 包含 } h_v^{(l)}$$

添加自环使得 $\hat{A}$ 的对角线非零，确保每个节点在聚合时「看到」自己。这对于保持节点个体特征至关重要，尤其当节点自身特征包含类别判别信息时。
