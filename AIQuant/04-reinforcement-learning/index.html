交易环境建模

强化学习将交易建模为马尔可夫决策过程 (MDP)：智能体在每个时刻观察市场状态（价格历史、持仓、资金）， 选择一个动作（买入/卖出/持有），环境返回奖励（盈亏）并转移到下一个状态。 智能体的目标是学习一个策略 $\pi(a|s)$，使累积奖励最大化。

$$G_t = \sum_{k=0}^{T-t} \gamma^k R_{t+k+1}, \quad \pi^* = \arg\max_\pi \mathbb{E}_\pi[G_t]$$

Q-Learning 交易

Q-Learning 使用一张 Q 表记录每个状态-动作对的期望回报。在每一步中，智能体根据 $\epsilon$-贪心策略选择动作， 并用 Bellman 方程更新 Q 值。随着训练推进，Q 表逐渐收敛，策略趋于最优。

$$Q(s,a) \leftarrow Q(s,a) + \alpha \big[ r + \gamma \max_{a'} Q(s',a') - Q(s,a) \big]$$

DQN 交易

Deep Q-Network (DQN) 用神经网络近似 Q 函数，解决状态空间过大时 Q 表无法覆盖的问题。 经验回放 (Experience Replay) 打破数据相关性，目标网络 (Target Network) 稳定训练过程。 $\epsilon$ 探索率随训练逐步衰减，从探索转向利用。

$$\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}} \left[ \big( r + \gamma \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \big)^2 \right]$$

策略梯度方法

策略梯度直接优化策略网络的参数，输出动作的概率分布。Actor-Critic 架构结合了策略梯度（Actor）和 价值估计（Critic），利用优势函数 $A(s,a) = Q(s,a) - V(s)$ 降低方差。与 Q-Learning 相比， 策略梯度能处理连续动作空间，更适合精细的仓位管理。

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a|s) \cdot A(s,a) \right]$$
