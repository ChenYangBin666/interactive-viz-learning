软间隔 Soft Margin

允许一定的误分类，在间隔最大化与分类精度之间取得平衡

1

硬间隔的局限

在之前的模块中，我们假设数据是线性可分的。硬间隔 SVM 要求所有样本都被正确分类且位于间隔之外：

$$y_i(\mathbf{w} \cdot \mathbf{x}_i + b) \geq 1, \quad \forall i$$

但现实数据几乎总包含噪声和离群点，使得两类产生重叠。此时不存在能将两类完全分开的超平面。

点击「添加噪声」按钮，观察原本可分的数据变得不可分，硬间隔 SVM 失败。

状态： 线性可分
2

松弛变量 \(\xi_i\)

为了处理不可分的情况，我们引入松弛变量 $\xi_i \geq 0$，放宽约束：

$$y_i(\mathbf{w} \cdot \mathbf{x}_i + b) \geq 1 - \xi_i$$

松弛变量的含义：

  • $\xi_i = 0$：正确分类且在间隔外
  • $0 < \xi_i < 1$：在间隔内，但仍正确分类
  • $\xi_i \geq 1$：被错误分类
$\xi=0$（正确）
$0<\xi<1$（间隔内）
$\xi\geq1$（错误）
3

C 参数的作用

软间隔 SVM 的优化目标是：

$$\min_{\mathbf{w},b,\xi} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i=1}^n \xi_i$$

参数 C 控制着间隔大小与误分类惩罚之间的权衡：

  • C 很小：容忍更多违反 → 宽间隔 → 可能欠拟合
  • C 很大：严格惩罚违反 → 窄间隔 → 可能过拟合

合页损失 Hinge Loss

软间隔 SVM 的损失函数可以用合页损失（hinge loss）表示：

$$\ell_{\text{hinge}}(y, f(x)) = \max(0, 1 - y \cdot f(x))$$

总优化目标等价于：

$$\min_{\mathbf{w},b} \frac{1}{2}\|\mathbf{w}\|^2 + C \sum_{i=1}^n \max(0, 1 - y_i f(x_i))$$

合页损失是 0-1 损失的凸上界，它有几个重要性质：

  • 当 $y \cdot f(x) \geq 1$ 时，损失为 0
  • 当 $y \cdot f(x) < 1$ 时，损失线性增加
  • 凸函数 → 便于优化
