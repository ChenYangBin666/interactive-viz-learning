生物神经元 vs 人工神经元

人工神经元是对生物神经元的数学简化。左边是生物版本，右边是数学版本 — 信号自动流过两者，观察它们的对应关系。

生物神经元

⟷树突 = 输入
⟷胞体 = 求和
⟷轴突 = 输出

人工神经元

生物结构 功能 人工对应 数学表示
树突 (Dendrites)接收信号输入 (Inputs)\(x_1, x_2, \ldots\)
突触强度 (Synapse)信号加权权重 (Weights)\(w_1, w_2, \ldots\)
胞体 (Soma)整合信号加权求和\(z = \sum w_i x_i + b\)
轴突丘 (Axon Hillock)阈值判断激活函数\(\sigma(z)\)
轴突 (Axon)传出信号输出 (Output)\(a = \sigma(z)\)

单个神经元的计算

拖动滑块调整输入和权重，观察神经元如何实时计算输出。先加权求和得到 \(z\)，再通过 Sigmoid 激活得到 \(a\)。

输入 (Inputs)

1.0
0.5
-0.3

权重 (Weights)

0.8
-0.5
1.2

偏置 (Bias)

0.0
z = (0.8)(1.0) + (-0.5)(0.5) + (1.2)(-0.3) + 0.0 = 0.19
a = σ(0.19) = 0.547

感知机与线性分类

感知机用一条直线将二维平面分成两类。选择不同数据集，拖动滑块调整决策边界。注意：XOR 问题无法被单条直线解决!

决策边界参数

1.0
-1.5
w₁x₁ + w₂x₂ + b = 0
1.0·x₁ + 1.0·x₂ - 1.5 = 0
XOR 问题：无论怎么调整参数，一条直线都无法正确分类所有四个点。这正是为什么我们需要多层网络!

从单神经元到网络

单个神经元只能做线性分类。但当我们把多个神经元堆叠成层、加上非线性激活，就能逼近任意复杂的函数。点击按钮，看网络如何生长。
