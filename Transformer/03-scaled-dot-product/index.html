模块 03: 缩放点积注意力

Scaled Dot-Product Attention -- Transformer 最核心的计算单元

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
1

线性投影: X → Q, K, V

输入序列 "我 喜欢 深度 学习" 由 4 个 token 组成，每个 token 被嵌入为 8 维向量，形成输入矩阵 X（4×8）。

通过三个可学习的权重矩阵 $W_Q, W_K, W_V$（均为 8×8），将 X 分别投影为查询 Q、键 K、值 V：

$Q = XW_Q, \quad K = XW_K, \quad V = XW_V$

每个投影赋予相同的输入不同的"角色"：Q 表示"我在寻找什么"，K 表示"我能提供什么"，V 表示"我实际携带的信息"。

2

QKT 计算 -- 相似度矩阵

将查询矩阵 Q 与键矩阵的转置 KT 相乘，得到 原始注意力分数矩阵（4×4）。每个元素 $s_{ij}$ 表示第 $i$ 个 token 对第 $j$ 个 token 的"关注程度"。

$\text{Scores} = QK^T$

矩阵乘法的本质：Q 的第 $i$ 行与 KT 的第 $j$ 列做点积，向量越相似 → 点积越大 → 注意力越高。

3

缩放 -- 为什么除以 √dk

当维度 $d_k$ 较大时，点积的值也会变大。大的输入送入 softmax 会使输出极端化（接近 one-hot），导致梯度消失、训练困难。

除以 $\sqrt{d_k}$ 将方差稳定在 1 附近，让 softmax 工作在梯度充足的区域。

$\text{Scaled} = \frac{QK^T}{\sqrt{d_k}}$
8

未缩放 softmax

原始分数直接送入 softmax

缩放后 softmax

分数除以 √d_k 后送入 softmax

直觉：缩放使得 softmax 的输出分布更加平滑、均匀，每个位置都能获得梯度信号，模型训练更稳定。

4

Softmax -- 归一化为概率

对缩放后的分数矩阵逐行应用 softmax，将每行转换为概率分布（非负，行和为 1）。这就是注意力权重。

$\alpha_{ij} = \frac{\exp(s_{ij})}{\sum_k \exp(s_{ik})}$

每一行代表一个 token 的注意力分布：它"看向"其他 token 的权重总和为 1。

5

完整流程 -- 加权求和得到输出

最后一步：用注意力权重对V（值）矩阵做加权求和，输出矩阵每一行都是 V 中各行的加权组合。

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$
