1. 感知机 -- 最简单的神经元

感知机接收多个输入，对每个输入乘以权重，再加上偏置，最后通过激活函数产生输出：

$$y = \sigma\!\bigl(w_1 x_1 + w_2 x_2 + b\bigr)$$

3. 全连接层

全连接层（Dense Layer）是神经网络最基本的组件。每个输入节点与每个输出节点之间都有一条带权重的连接：

$$\mathbf{y} = \text{ReLU}\!\bigl(\mathbf{W}\mathbf{x} + \mathbf{b}\bigr)$$

4. 多层网络

通过堆叠多个全连接层，网络能够学习越来越复杂的模式。层数越深，决策边界越复杂。

更多的隐藏层和神经元可以表达更复杂的函数，但也更容易过拟合。尝试调整参数，观察决策边界的变化。

5. 前向传播完整流程

以一个 2-3-2 网络为例，逐步跟踪数据从输入到输出的完整计算过程。

$$\mathbf{x} \xrightarrow{W_1, b_1} \mathbf{z}_1 \xrightarrow{\text{ReLU}} \mathbf{a}_1 \xrightarrow{W_2, b_2} \mathbf{z}_2 \xrightarrow{\text{softmax}} \hat{\mathbf{y}}$$
