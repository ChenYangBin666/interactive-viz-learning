局部性原理

存储层级之所以有效，是因为程序的内存访问具有局部性 (Locality)。 时间局部性意味着最近访问的数据可能很快再次被访问；空间局部性意味着邻近地址的数据可能很快被访问。

// 时间局部性示例：循环中重复访问同一变量 int sum = 0; for (int i = 0; i < 1000; i++) { sum += arr[i]; // sum 被反复读写 } // sum 在整个循环期间 // 都留在寄存器/L1 Cache 中

观察：热图中，颜色越亮表示该地址被访问的次数越多。少数地址被高频访问，体现了时间局部性。

// 空间局部性示例：顺序遍历数组 int arr[1024]; for (int i = 0; i < 1024; i++) { arr[i] *= 2; // 连续访问相邻地址 } // arr[0], arr[1], arr[2], ... // 一个Cache行(64B)可容纳16个int

观察：访问波沿着地址空间连续推进，附近的地址被依次访问。一次缓存缺失会加载整个缓存行，后续多次访问命中。

⚖

速度-容量-成本权衡

不存在一种既快速又大容量又便宜的存储技术。存储层级的存在正是为了弥补这一根本矛盾： 用少量的快速存储缓存频繁访问的数据，用大量的慢速存储保存全部数据。
