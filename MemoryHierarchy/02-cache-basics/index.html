什么是Cache

Cache（高速缓存）是位于CPU与主存之间的小容量、高速度存储器。它利用程序的局部性原理，将最近访问的数据保留在离CPU最近的地方，从而大幅降低平均访问延迟。

局部性原理：时间局部性 — 刚访问的数据很快会再次访问；空间局部性 — 访问某地址后，附近地址也很可能被访问。

地址分解

CPU发出的内存地址需要拆分成三部分才能查找Cache：标记(Tag)用于唯一标识数据块，索引(Index)确定数据在Cache中的位置，偏移(Offset)定位块内的具体字节。

$$\text{地址} = [\underbrace{\text{Tag}}_{\text{标识块}}\ |\ \underbrace{\text{Index}}_{\text{定位组}}\ |\ \underbrace{\text{Offset}}_{\text{块内偏移}}]$$

直接映射Cache

直接映射是最简单的Cache映射方式：每个内存块只能映射到Cache中唯一确定的一行。映射规则为：

$$\text{Cache行号} = \text{内存块号} \mod \text{Cache总行数}$$

优点是硬件实现简单、查找速度快；缺点是容易产生冲突未命中 — 两个不同地址映射到同一行时互相驱逐。

全相联Cache

全相联映射允许内存块放入Cache的任意位置。查找时需要将请求的Tag与Cache中所有行的Tag并行比较，因此不会有冲突未命中。

优点：无冲突未命中，利用率最高。
缺点：需要大量比较器，硬件成本高，仅适用于小容量Cache（如TLB）。

组相联Cache

组相联是直接映射与全相联的折中方案：将Cache分成若干组(Set)，每组包含多个路(Way)。地址先根据Index定位到某组，再在该组内的多路中任意存放。

$$N\text{路组相联：每组} N \text{行，共} \frac{\text{Cache行数}}{N} \text{个组}$$

1路组相联 = 直接映射；Cache行数路组相联 = 全相联
