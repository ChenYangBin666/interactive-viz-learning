XGBoost / 模块 03

XGBoost 目标函数

深入理解 XGBoost 如何通过泰勒展开构建目标函数，并推导出最优叶子权重与分裂增益公式。

1

泰勒展开直觉

泰勒展开允许我们用多项式来近似任意可微函数。在点 $x_0$ 处，一阶近似（切线）给出方向， 二阶近似（抛物线）进一步捕捉曲率信息。XGBoost 正是利用二阶展开来近似损失函数。

$$f(x_0+\Delta x) \approx f(x_0) + f'(x_0)\Delta x + \frac{1}{2}f''(x_0)\Delta x^2$$

梯度 = 一阶导数 $f'(x)$：告诉我们函数的变化方向和速率

Hessian = 二阶导数 $f''(x)$：告诉我们函数的曲率（弯曲程度）

0.0
原函数 $f(x)$
一阶近似（切线）
二阶近似（抛物线）
2

XGBoost 目标函数推导

XGBoost 的核心创新在于对目标函数进行二阶泰勒展开，使得优化过程更高效且可推导出解析解。 下面逐步构建完整的目标函数。

起点：目标函数 = 损失 + 正则化
第一步：在第 $t$ 轮添加新树 $f_t$
第二步：对损失函数做二阶泰勒展开
第三步：移除常数项（与 $f_t$ 无关的项）
第四步：定义 $g_i = \partial_{\hat{y}^{(t-1)}} L(y_i, \hat{y}_i^{(t-1)})$，$h_i = \partial^2_{\hat{y}^{(t-1)}} L(y_i, \hat{y}_i^{(t-1)})$
3

梯度 $g_i$ 与 Hessian $h_i$

不同的损失函数产生不同的梯度和 Hessian。$|g_i|$ 越大，说明该样本当前预测偏差越大，需要更多修正。 $h_i$ 反映了对该样本预测调整的"置信度"。

红色条 = 负值（预测偏高），绿色条 = 正值（预测偏低）。条越长，需要的修正越大。

4

最优叶子权重

对于落入某个叶子节点的样本集合，最优叶子权重可以解析求解。 正则化参数 $\lambda$ 越大，叶子权重越趋向零（收缩效果）。

$$w^* = -\frac{\sum_{i \in I_j} g_i}{\sum_{i \in I_j} h_i + \lambda}$$

5

从目标函数到分裂增益

分裂增益衡量一次分裂能带来多少目标函数的改进。只有当增益大于 $\gamma$（复杂度代价）时，分裂才值得进行。

$$\text{Gain} = \frac{1}{2}\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right] - \gamma$$
