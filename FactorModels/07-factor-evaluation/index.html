IC 与 Rank IC

信息系数 (Information Coefficient, IC) 衡量因子值与未来收益的截面相关性，是因子有效性的核心指标。

$$\text{IC}_t = \text{Corr}(f_t, r_{t+1})$$ $$\text{Rank IC}_t = \text{SpearmanCorr}(\text{rank}(f_t), \text{rank}(r_{t+1}))$$

Rank IC 对异常值更稳健，在实际研究中更常用。IC_IR = mean(IC) / std(IC) 衡量 IC 的信噪比，类比夏普比率。

  • Pearson IC: 线性相关，受极端值影响大
  • Spearman Rank IC: 秩相关，仅关注排序
  • IC_IR: 越高说明因子预测越稳定
  • IC > 0 占比: 衡量因子方向一致性

判断标准: |mean IC| > 0.03 有一定预测力；IC_IR > 0.5 非常优秀；IC > 0 占比 > 55% 为理想。实际中 Rank IC 约 0.03~0.05 已是不错的因子。

分层回测

将股票按因子值排序分为五组 (Q1 最高 ~ Q5 最低)，观察各组累计收益是否呈单调递增/递减关系。

$$\text{Long-Short Return} = r_{Q1} - r_{Q5}$$ $$\text{年化收益} = \left(\frac{V_T}{V_0}\right)^{252/T} - 1$$
  • 理想因子：Q1 ~ Q5 累计收益严格单调
  • 多空组合 (Q1 - Q5) 应有稳定正收益
  • 年化收益差 (spread) 越大越好
  • 换手率与再平衡频率需权衡交易成本

检验要点: 单调性是否成立？多空收益是否显著？各层年化收益差距是否足够大？若中间层 (Q2~Q4) 交错，则因子区分度不足。

因子收益率与 t 统计量

Fama-MacBeth 回归：每期对截面做回归，因子暴露作为自变量，个股收益作为因变量。

$$r_{i,t} = \alpha_t + \gamma_t f_{i,t} + \epsilon_{i,t}$$ $$t_{OLS} = \frac{\bar{\gamma}}{\text{se}(\bar{\gamma})}, \quad t_{NW} = \frac{\bar{\gamma}}{\text{se}_{NW}(\bar{\gamma})}$$
  • $\gamma_t$ 为第 $t$ 期因子收益率 (factor premium)
  • OLS t-stat 假设 $\gamma_t$ 独立同分布
  • Newey-West 调整序列自相关，更保守可靠
  • |t| > 2 → 5% 水平统计显著；|t| > 3 → 更强证据

注意: 多重检验问题 — 检验大量因子时，需调整显著性阈值 (如 Bonferroni 或 FDR 校正)。单因子 |t| > 2 不保证样本外有效。

因子衰减分析

因子预测力随持有期延长而衰减。衰减速度决定了最优调仓频率和因子本质 (alpha 还是 risk)。

$$\text{IC}(h) = \text{Corr}(f_t, r_{t \to t+h})$$ $$\text{半衰期}: h_{1/2} \text{ 满足 } \text{IC}(h_{1/2}) = \tfrac{1}{2}\text{IC}(1)$$
  • 快衰减 (Alpha 型): 半衰期 3~10 天，动量/反转类因子
  • 慢衰减 (风险型): 半衰期 30~60+ 天，价值/质量类因子
  • 自相关 (ACF) 衡量因子值自身的持续性
  • 高 ACF + 快 IC 衰减 → 因子排序稳定但预测力短暂
15天

实践启示: 若半衰期 = 5 天，月度调仓会丢失大部分信号；若半衰期 = 40 天，日度调仓的换手成本远超收益增益。

因子拥挤度

当过多投资者使用同一因子时，因子变得"拥挤"：预期收益下降、波动率上升、回撤加大、反转风险升高。

拥挤度衡量指标:

  • 估值价差 (Valuation Spread): 多头组与空头组的估值差距，拥挤时扩大
  • 做空比例 (Short Interest): 空头侧股票被做空比例上升
  • 两两相关性 (Pairwise Corr): 因子内部股票收益高度同步
  • 因子动量: 近期表现好的因子更易拥挤
30%

状态正常: 因子拥挤度较低，预期收益正常，回撤风险可控。
