Common Kernel Functions — 不同核函数的特性、参数与适用场景

1

线性核 Linear Kernel

$$K(\mathbf{x}, \mathbf{y}) = \mathbf{x} \cdot \mathbf{y} = \sum_{i=1}^{n} x_i y_i$$

线性核是最简单的核函数，本质上没有进行任何特征变换——它等价于在原始空间中直接计算内积。使用线性核的 SVM 得到的决策边界是一条直线（二维）或超平面（高维）。

特征映射
线性核对应恒等映射 $\phi(\mathbf{x}) = \mathbf{x}$，即不做任何变换。这意味着使用线性核的 SVM 完全等价于标准线性 SVM。

核心特点：

• 无超参数需要调节，使用最简单

• 训练与预测速度最快，计算复杂度 $O(n)$

• 适合高维稀疏数据（文本分类 TF-IDF、基因表达数据）

• 当特征数 $\gg$ 样本数时，数据在原始空间往往已经线性可分

局限：对于低维非线性数据（如环形分布），线性核无法正确分类。此时需要使用非线性核函数。

多项式核 Polynomial Kernel

$$K(\mathbf{x}, \mathbf{y}) = (\mathbf{x} \cdot \mathbf{y} + c)^d$$

多项式核将数据隐式映射到高维多项式特征空间。两个关键参数决定了决策边界的形状：

阶数 $d$ — 控制边界复杂度：

• $d = 2$：二次曲线（椭圆、双曲线、抛物线）

• $d = 3$：三次曲线，能拟合更复杂的模式

• $d \geq 4$：高度灵活，但数值不稳定且易过拟合

常数 $c$ — 影响低阶项与高阶项的权重平衡：

• $c = 0$：齐次多项式核，仅包含最高阶交叉项

• $c > 0$：包含低阶项，模型更稳定

$d=2$, $c=1$ 时的特征映射 (2D)
$\phi(x_1, x_2) = (x_1^2, x_2^2, \sqrt{2}\,x_1 x_2, \sqrt{2}\,x_1, \sqrt{2}\,x_2, 1)$
2维输入映射为6维特征空间

注意：阶数越高，过拟合风险越大。实践中 $d$ 很少超过 5。调节滑块观察不同阶数下决策边界的变化。

RBF / 高斯核 Gaussian Kernel

$$K(\mathbf{x}, \mathbf{y}) = \exp\!\left(-\gamma \|\mathbf{x} - \mathbf{y}\|^2\right)$$

RBF（径向基函数）核是 SVM 中最常用、最重要的核函数。它将数据映射到无穷维的希尔伯特空间，理论上能够拟合任意复杂的决策边界。

核心参数 $\gamma$ 控制每个样本的"影响半径"：

• $\gamma$ 很小 (如 0.01)：高斯钟形很宽 → 每个点的影响范围大 → 决策边界平滑简单 → 可能欠拟合

• $\gamma$ 适中 (如 0.3-1)：平衡拟合能力与泛化能力

• $\gamma$ 很大 (如 10)：高斯钟形很窄 → 每个点只影响附近区域 → 决策边界紧贴训练数据 → 可能过拟合

首选推荐：当你不确定使用哪种核时，优先尝试 RBF。它是 scikit-learn 等库的默认核函数。配合网格搜索调节 $\gamma$ 和 $C$ 两个参数即可获得良好效果。

直觉理解：高斯山丘
RBF 核相当于在每个支持向量位置放置一个高斯"山丘"（正类朝上、负类朝下），决策边界就是所有山丘叠加后高度为零的等高线。右侧可视化中，颜色深浅表示决策函数值的大小。

$\gamma$ 与 $\sigma$ 的关系：$\gamma = \frac{1}{2\sigma^2}$，其中 $\sigma$ 是高斯函数的标准差。$\gamma$ 越大即 $\sigma$ 越小，高斯越窄。

实践选择建议

首选 RBF

不确定数据分布时，优先使用 RBF 核。它能适应几乎所有非线性模式。通过交叉验证搜索最佳 $\gamma$ 和 $C$。

高维用线性

当特征维度远大于样本数时（如文本分类 $n > 10000$），线性核足够且训练速度快几个数量级。

已知结构用多项式

如果领域知识表明数据具有多项式关系（如计算机视觉中的交叉特征），直接使用多项式核，从低阶开始尝试。

Sigmoid 需谨慎

Sigmoid 核并非对所有参数都满足 Mercer 条件（不一定正定），实践中较少使用。它更多是理论上与神经网络的联系。

调参技巧：对于 RBF 核，常用网格搜索策略为 $C \in \{0.1, 1, 10, 100\}$，$\gamma \in \{0.001, 0.01, 0.1, 1\}$，配合 5 折交叉验证选择最佳组合。数据预处理（标准化/归一化）对核函数效果至关重要——未归一化的特征会导致某些维度主导距离计算。

常见误区：不要因为 RBF 核在训练集上准确率 100% 就认为模型很好——过拟合的 RBF（$\gamma$ 过大）会记住每个训练点但泛化能力很差。始终使用验证集或交叉验证评估模型性能。
