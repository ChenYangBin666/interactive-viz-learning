GoogLeNet / Inception (2014)

GoogLeNet 引入了 Inception 模块，核心思想是：在同一层中并行使用不同大小的卷积核，让网络自己学习最佳的特征尺度。

核心思想：不确定用哪种卷积核？那就全都用，然后拼起来！

ResNet — 残差连接 (2015)

何恺明等人提出的 残差网络 (ResNet) 是深度学习历史上最重要的突破之一。它通过跳跃连接 (skip connection) 解决了深层网络的退化问题。

核心公式：$$\mathcal{H}(x) = \mathcal{F}(x) + x$$

网络只需学习残差 $\mathcal{F}(x) = \mathcal{H}(x) - x$，而非完整映射。

DenseNet — 密集连接 (2017)

DenseNet 将跳跃连接的思想推向极致：每一层都与之前所有层相连。不同于 ResNet 的元素相加，DenseNet 使用通道拼接 (concatenation)。

核心公式：$$x_l = H_l\big([x_0, x_1, \ldots, x_{l-1}]\big)$$

第 $l$ 层的输入是前面所有层输出的拼接。

16
层数: 1 | 连接数: 0 | 输出通道: 16

特征复用

DenseNet 的关键优势：每层都能直接访问损失函数的梯度和原始输入，促进特征复用，大幅减少参数量。

连接数公式：L 层 Dense Block 有 $\frac{L(L+1)}{2}$ 条直接连接

DenseNet 完整架构

多个 Dense Block 之间用 Transition Layer（1×1 Conv + 2×2 AvgPool）连接，逐步压缩空间尺寸和通道数。

Input → Dense Block 1 → Transition 1 → Dense Block 2 → Transition 2 → Dense Block 3 → GAP + FC

Transition Layer 作用：压缩率 $\theta = 0.5$，通道减半，空间减半。防止通道数爆炸增长。

总结趋势：从 GoogLeNet 的"更宽"(parallel paths)，到 ResNet 的"更深"(skip connections)，再到 DenseNet 的"更密"(dense connections) — 核心目标始终是：在不退化的前提下充分利用深度。

延伸思考：这三种连接方式并非互斥。后续工作如 Inception-ResNet 结合了 Inception 和 ResNet 的优势，而 ResNeXt 则将 Inception 的多路径思想用分组卷积统一表达。架构搜索 (NAS) 更是自动化地组合这些基本构件。
