模块 02: 原始 RNN (Vanilla RNN)

理解循环神经网络的核心结构 — 信息如何在时间步之间流动

1

RNN 基本结构

核心公式

循环神经网络 (Recurrent Neural Network, RNN) 是处理序列数据的经典模型。 与前馈网络不同，RNN 在每个时间步不仅接收当前输入，还接收上一步产生的隐藏状态， 从而形成一条跨越时间的"记忆链"。

核心公式：

$$h_t = \tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h)$$

1
$W_{xh} x_t$ — 将当前输入 $x_t$ 通过输入权重矩阵投影到隐藏空间
2
$W_{hh} h_{t-1}$ — 将上一步的隐藏状态 $h_{t-1}$ 通过循环权重矩阵进行变换
3
$+ b_h$ — 加上偏置项
4
$\tanh(\cdot)$ — 通过双曲正切激活函数，将输出压缩到 $[-1, 1]$ 范围内

其中各参数的维度：若隐藏层大小为 $d_h$，输入维度为 $d_x$，则 $W_{xh} \in \mathbb{R}^{d_h \times d_x}$， $W_{hh} \in \mathbb{R}^{d_h \times d_h}$，$b_h \in \mathbb{R}^{d_h}$。

权重共享

关键洞察

RNN 最关键的设计决策之一：所有时间步共享相同的权重矩阵。 无论序列有多长（5 步、50 步或 500 步），模型始终使用同一组 $W_{xh}$、$W_{hh}$ 和 $b_h$。

为什么要共享权重？

1. 参数效率：参数量与序列长度无关，可以处理任意长度的序列。

2. 泛化能力：在不同时间位置学到的模式可以迁移到其他位置。

3. 类比卷积：就像 CNN 在空间上共享卷积核，RNN 在时间上共享权重。

对比展开后的三个时间步，注意权重矩阵的颜色（相同颜色 = 相同参数）：

$$h_1 = \tanh(\color{#16c79a}{W_{xh}} x_1 + \color{#4fc3f7}{W_{hh}} h_0 + b_h)$$

$$h_2 = \tanh(\color{#16c79a}{W_{xh}} x_2 + \color{#4fc3f7}{W_{hh}} h_1 + b_h)$$

$$h_3 = \tanh(\color{#16c79a}{W_{xh}} x_3 + \color{#4fc3f7}{W_{hh}} h_2 + b_h)$$

RNN: 权重共享

所有时间步使用相同颜色 = 相同权重

MLP: 独立权重

每层使用不同颜色 = 不同权重矩阵

参数量对比：假设 $d_x=10, d_h=32, T=50$。RNN 参数量 = $d_h \times d_x + d_h^2 + d_h$ = 1,376（恒定）；MLP 逐层参数 = $T \times (d_h \times d_x + d_h)$ = 17,600（随 $T$ 线性增长）。

隐藏状态的含义

可视化

隐藏状态 $h_t \in \mathbb{R}^{d_h}$ 是 RNN 的"记忆"，它编码了从序列开始 到当前时间步 $t$ 为止的所有信息的压缩表示。

每个隐藏状态维度（即 $h_t$ 向量的每个分量）可以视为一个独立的"特征检测器"， 不同维度可能捕捉输入序列中的不同模式或特征。

信息瓶颈：所有历史信息必须压缩到一个固定长度的向量 $h_t$ 中。 当序列很长时，早期的信息会逐渐被"冲淡"——这是 Vanilla RNN 的核心局限， 也是后续 LSTM/GRU 要解决的问题。

输出与预测

应用

有了隐藏状态后，我们需要一个输出层将其映射到目标空间。输出公式为：

$$y_t = W_{hy} h_t + b_y$$

其中 $W_{hy} \in \mathbb{R}^{d_y \times d_h}$，$b_y \in \mathbb{R}^{d_y}$。 对于分类任务，$y_t$ 后面还会接一个 softmax 层；对于回归任务则直接使用。
