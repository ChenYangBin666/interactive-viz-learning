06 — 采样方法

从 DDPM 标准反向过程到 DDIM 加速采样，再到 DPM-Solver 高阶求解器 —— 探索如何用更少的步数生成高质量样本。

1

DDPM 采样回顾

DDPM 的标准反向过程需要从 \(T=1000\) 步纯噪声开始，逐步去噪：

$$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t, t)\right) + \sigma_t z$$

每一步都需要调用一次神经网络，因此 T=1000 步 = 1000 次网络推理，非常缓慢。

瓶颈：实际生成一张 256x256 图像可能需要数十秒到数分钟。采样效率是扩散模型最大的挑战之一。

DDIM 加速

DDIM（Denoising Diffusion Implicit Models）的核心思想：跳步采样！

$$x_{\tau_{i-1}} = \sqrt{\bar\alpha_{\tau_{i-1}}}\underbrace{\left(\frac{x_{\tau_i} - \sqrt{1-\bar\alpha_{\tau_i}}\epsilon_\theta(x_{\tau_i}, \tau_i)}{\sqrt{\bar\alpha_{\tau_i}}}\right)}_{\text{预测的 }x_0} + \sqrt{1-\bar\alpha_{\tau_{i-1}} - \sigma_{\tau_i}^2}\cdot\epsilon_\theta(x_{\tau_i}, \tau_i) + \sigma_{\tau_i}\epsilon$$

非马尔可夫过程允许从 \(x_t\) 直接跳到 \(x_{t-k}\)，大幅减少采样步数。下面对比不同步数的采样结果：

3

\(\eta\) 参数探索

DDIM 的 \(\eta\) 参数控制采样中的随机性：

$$\sigma_t = \eta \cdot \sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}} \cdot \sqrt{1 - \frac{\bar\alpha_t}{\bar\alpha_{t-1}}}$$
  • \(\eta = 0\)：完全确定性，相同噪声 \(\to\) 相同结果
  • \(\eta = 1\)：等价于 DDPM，完全随机
  • \(0 < \eta < 1\)：介于两者之间
0.00

当 \(\eta=0\) 时，5 次运行将产生完全相同的轨迹；\(\eta\) 越大，轨迹差异越明显。

DPM-Solver

将反向扩散过程视为常微分方程（ODE）：

$$\frac{dx}{dt} = f(x, t)$$

不同的数值求解器精度不同：

  • Euler 方法（1 阶）：每步线性近似，需要很多步
  • DPM-Solver-2（2 阶）：利用中间点信息，更精确
  • DPM-Solver-3（3 阶）：高阶 Taylor 展开，极少步数
