自注意力子层

在编码器中，自注意力的查询(Q)、键(K)、值(V) 全部来自同一输入 $X$：

$$Q = XW^Q, \quad K = XW^K, \quad V = XW^V$$

每个 token 都可以关注序列中所有其他 token（包括自身），这使得编码器具有双向注意力能力。

层归一化

对每个 token 的特征向量独立地归一化（注意：是沿特征维度，不是 batch 维度）：

$$\text{LayerNorm}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$$

前馈网络 (FFN)

每个编码器层的第二个子层是一个逐位置的前馈网络，对每个 token 独立地进行非线性变换：

$$\text{FFN}(x) = \max(0,\; xW_1 + b_1)\,W_2 + b_2$$

典型配置：$d_{ff} = 4 \times d_{model}$，先扩展再压缩，让模型在更高维空间进行特征变换。

ReLU 激活效果

ReLU 将所有负值置零，只保留正值。这引入了稀疏性——网络学会用不同的"专家神经元"处理不同特征。

原始论文使用 ReLU，后续变体（GPT-2, BERT 等）常使用 GELU。
