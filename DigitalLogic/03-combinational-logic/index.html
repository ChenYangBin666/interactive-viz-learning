组合逻辑电路

多路选择器、解码器、编码器、比较器 —— 组合逻辑的经典功能模块

1

2:1 多路选择器 (MUX)

多路选择器根据选择信号 S，从多个输入中选出一个作为输出。2:1 MUX 是最基本的选择器单元。

$Y = \overline{S} \cdot I_0 + S \cdot I_1$
Y = 0
SI0I1Y
当 S=0 时，NOT 门使上方 AND 门导通，Y = I0；
当 S=1 时，下方 AND 门导通，Y = I1。
2

4:1 MUX 与级联

4:1 MUX 可以由三个 2:1 MUX 级联构建。两根选择线 S1、S0 可选出 4 路输入之一。

$Y = \overline{S_1}\,\overline{S_0}\cdot I_0 + \overline{S_1}\,S_0\cdot I_1 + S_1\,\overline{S_0}\cdot I_2 + S_1\,S_0\cdot I_3$
Y = 0
S1 控制第一级选择：S1=0 选上半部分 (I0, I1)，S1=1 选下半部分 (I2, I3)。
S0 控制第二级：在已选的两路中再选一路。
级联原理：任意 N:1 MUX 都可以用更小的 MUX 构建。
3

解码器 (Decoder)

解码器将 n 位二进制输入转换为 $2^n$ 条输出线中的一条，常用于存储器地址译码。

$D_i = EN \cdot m_i$ ，其中 $m_i$ 是第 $i$ 个最小项
输出： D0=1 D1=0 D2=0 D3=0
ENA1A0D0D1D2D3
使能端 EN：EN=0 时所有输出为 0，可用于级联构建更大的解码器。
应用：存储器地址译码 —— 用高位地址选择芯片，低位地址选择芯片内单元。
4

编码器与优先编码器

编码器是解码器的逆操作：将 $2^n$ 条输入线编码为 n 位二进制输出。优先编码器能处理多输入同时有效的冲突。

普通 4-to-2 编码器

一次只允许一个输入为 HIGH

编码输出： A1=0, A0=0

优先编码器 (Priority Encoder)

多个输入有效时，最高优先级获胜

优先输出： A1=0, A0=0, V=0
普通编码器：假设同一时刻只有一个输入为 1，否则输出不确定。
优先编码器：D3 优先级最高，D0 最低。V (Valid) 位指示是否有任何有效输入。
5

比较器 (Comparator)

比较器比较两个二进制数的大小关系，输出 A>B、A=B、A<B 三种结果。

4 位比较器

A: = 0
B: = 0
A > B
A = B
A < B
比较从最高位 (MSB) 开始逐位比较：
若 A3 > B3 则 A > B（无需比较低位）；
若 A3 = B3 则继续比较 A2 与 B2，以此类推。
级联：多片 4 位比较器可通过级联输入 (Gt_in, Eq_in, Lt_in) 扩展为更大位宽。
6

组合电路设计流程

以 BCD 到七段显示译码器为例，完整演示组合电路的设计过程。

问题描述

设计一个将 4 位 BCD 码 (0000~1001) 转换为七段显示器信号的译码器。

输入：4 位 BCD 码 D3 D2 D1 D0（表示 0~9）

输出：7 个段信号 a, b, c, d, e, f, g

段名排列：

上 = a, 右上 = b, 右下 = c

下 = d, 左下 = e, 左上 = f, 中 = g

0

真值表

列出 BCD 输入 (0~9) 对应的七段输出。10~15 为无效输入 (Don't Care)。

D3D2D1D0abcdefg数字

卡诺图化简（以 a 段为例）

将真值表中 a 段的值填入 4 变量卡诺图，圈出最大质蕴含项。

灰色格为 Don't Care (X)，可被视为 0 或 1 以利于化简。

化简后的逻辑表达式

利用卡诺图化简得到各段的最简 SOP 表达式：

$a = D_3 + D_1 + D_2 D_0 + \overline{D_2}\,\overline{D_0}$
$b = \overline{D_2} + D_1 D_0 + \overline{D_1}\,\overline{D_0}$
$c = D_2 + \overline{D_1} + D_0$
$d = \overline{D_2}\,\overline{D_0} + D_1\,\overline{D_0} + D_2\,\overline{D_1}\,D_0 + \overline{D_2}\,D_1 + D_3$
$e = \overline{D_2}\,\overline{D_0} + D_1\,\overline{D_0}$
$f = D_3 + \overline{D_1}\,\overline{D_0} + D_2\,\overline{D_1} + D_2\,\overline{D_0}$
$g = D_3 + D_2\,\overline{D_1} + \overline{D_2}\,D_1 + D_1\,\overline{D_0}$

最终电路与验证

输入 BCD 码，查看七段显示器的输出结果。

BCD: = 0
段输出： a=1 b=1 c=1 d=1 e=1 f=1 g=0
