LSTM 门控机制

长短期记忆网络 — 通过精妙的门控设计解决长程依赖问题

1

LSTM 整体架构

LSTM（长短期记忆）通过引入细胞状态（Cell State）和三个门控机制，让网络能够学习何时记住、何时遗忘、何时输出信息。细胞状态像一条"传送带"，信息可以几乎无损地流过整个序列。

遗忘门 (Forget)
输入门 (Input)
候选值 (Candidate)
输出门 (Output)

核心公式

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f) \quad \text{— 遗忘门}$$
$$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \quad \text{— 输入门}$$
$$\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C) \quad \text{— 候选值}$$
$$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad \text{— 输出门}$$
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \quad \text{— 细胞状态更新}$$
$$h_t = o_t \odot \tanh(C_t) \quad \text{— 隐藏状态输出}$$
2

遗忘门

遗忘门决定细胞状态中哪些信息应该被丢弃。它查看 $h_{t-1}$ 和 $x_t$，为细胞状态中的每个值输出 0 到 1 之间的数字：0 表示完全遗忘，1 表示完全保留。

$$f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$$
0 完全遗忘 1 完全保留 0.80

上方展示细胞状态中的 4 个值如何被遗忘门逐元素相乘。拖动滑块观察遗忘效果。

语言模型示例

假设模型在处理句子"小明喜欢猫。小红喜欢狗。____的宠物是..."

当遇到新主语"小红"时，遗忘门会将旧主语"小明"的相关信息从细胞状态中清除（$f_t \approx 0$），为新信息腾出空间。

3

输入门与候选值

输入门分两步工作：首先，输入门 $i_t$ 决定哪些位置需要更新；然后，候选值 $\tilde{C}_t$ 生成新的候选信息。两者逐元素相乘后加入细胞状态。

$$i_t = \sigma(W_i [h_{t-1}, x_t] + b_i) \quad \text{— 输入门（选择更新哪些位置）}$$
$$\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C) \quad \text{— 候选值（新信息）}$$
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t \quad \text{— 完整的细胞状态更新}$$
0 阻断 1 通过 0.70

左侧为候选值 $\tilde{C}_t$，中间为输入门 $i_t$ 的过滤，右侧为最终加入细胞状态的新信息。

4

输出门

输出门决定细胞状态的哪些部分成为当前的隐藏状态输出 $h_t$。细胞状态先通过 $\tanh$ 压缩到 [-1, 1]，再由输出门过滤。

$$o_t = \sigma(W_o [h_{t-1}, x_t] + b_o) \quad \text{— 输出门}$$
$$h_t = o_t \odot \tanh(C_t) \quad \text{— 隐藏状态}$$

完整单步数据流

1. 遗忘门：决定丢弃旧信息 $f_t \odot C_{t-1}$
2. 输入门：选择新信息通道 $i_t$
3. 候选值：生成新信息 $\tilde{C}_t$
4. 更新细胞状态 $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$
5. 输出门 + 隐藏状态 $h_t = o_t \odot \tanh(C_t)$

梯度流对比：LSTM vs 原始 RNN

LSTM 的细胞状态"高速公路"让梯度可以几乎无损地反向传播，有效缓解梯度消失问题。

LSTM 梯度流

关键洞察：LSTM 的细胞状态更新为 $C_t = f_t \odot C_{t-1} + \ldots$，反向传播时梯度乘以 $f_t$（接近 1），而非 RNN 中梯度乘以 $W_{hh}$ 的特征值（可能远大于或远小于 1），因此梯度保持稳定。
