组合 vs 时序电路

组合电路的输出仅取决于当前输入；时序电路的输出取决于当前输入和内部存储状态（记忆）。时序电路 = 组合电路 + 存储元件（反馈回路）。

关键区别

左侧：组合电路 — 改变输入后输出立即变化，没有记忆。

右侧：时序电路 — 输出取决于历史状态，存在反馈回路。

Y = 0 Q = 0

时序电路中的反馈回路使得输出可以影响自身的下一状态，这就是"记忆"的本质。

2

SR 锁存器 (SR Latch)

SR 锁存器由两个交叉耦合的 NOR 门构成，是最基本的存储元件。S (Set) 使 Q=1，R (Reset) 使 Q=0，S=R=1 为禁止状态。

控制面板

Q = 0 Q' = 1
S=R=1 为禁止状态！Q 和 Q' 均被强制为 0，释放后状态不确定。

特性表（NOR 型 SR 锁存器）

SRQ(next)说明
00Q(prev)保持
101置位
010复位
11X禁止
3

D 锁存器与 D 触发器

D 锁存器在 Enable 为高时透明传输，为低时锁存。D 触发器仅在时钟边沿捕获数据（边沿敏感）。

控制面板

Q = 0 Q = 0

电平敏感 vs 边沿敏感：锁存器在 Enable=1 时，Q 跟随 D 实时变化（透明）。触发器仅在时钟上升沿的瞬间采样 D 值。

时钟信号与边沿检测

时钟信号是时序电路的心跳。调整频率和占空比，观察上升沿/下降沿的位置。

建立时间与保持时间

数据必须在时钟边沿前（建立时间 Tsu）稳定，并在边沿后（保持时间 Th）维持不变，否则可能产生亚稳态。

亚稳态风险！输出可能振荡或取随机值。

亚稳态 (Metastability)：当数据在禁区内变化，触发器内部锁存的电压可能停留在 0 和 1 之间，导致不确定输出。

JK 与 T 触发器

JK 触发器解决了 SR 的禁止状态问题（J=K=1 时翻转）。T 触发器由 JK 导出（J=K=T），用于计数。
