稀疏特征问题

在实际机器学习任务中，特征矩阵往往是高度稀疏的。例如：

One-Hot 编码 文本 TF-IDF 交叉特征 多值类别特征

这意味着大量特征在大部分样本上取值为 0，为每个特征都构建直方图会浪费计算资源。

$$\text{稀疏度} = \frac{\text{零元素数量}}{\text{总元素数量}} \times 100\%$$

EFB 的核心思想：将这些互斥的稀疏特征捆绑为少量特征，大幅减少直方图的构建次数。

互斥特征检测

两个特征是"互斥"的，当它们很少同时取非零值。互斥特征对可以安全地合并为一个特征。

$$\text{冲突率}(F_i, F_j) = \frac{|\{k : x_{ki} \ne 0 \land x_{kj} \ne 0\}|}{n}$$

点击下方矩阵中的单元格来切换非零值，系统会实时检测哪些特征对是互斥的，并构建冲突图。

特征捆绑过程

通过偏移量编码将互斥特征合并为单个特征，保证不同原始特征的取值范围不重叠：

$$\text{Bundle}(x) = x_A + \text{offset}_A, \quad \text{offset}_A = 0, \; \text{offset}_B = \max(F_A) + 1$$

图着色算法

EFB 使用贪心图着色来确定特征分组：

  1. 构建冲突图：节点 = 特征，边 = 冲突对
  2. 按节点度数降序排列
  3. 依次为每个节点分配颜色（不与邻居冲突的最小颜色）
  4. 相同颜色的特征归入同一 Bundle

允许一定冲突阈值可以产生更激进的捆绑，用少量精度换取更大的加速。
