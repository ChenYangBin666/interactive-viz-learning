learning_rate 与 n_estimators 的权衡

热力图展示不同 learning_rate 和 n_estimators 组合下的验证得分。绿色方框标记最优区域，橙色虚线为早停线。

最优区域：中低 LR + 适量树
过拟合区：高 LR + 过多树
欠拟合区：极低 LR + 少树
早停线：最佳迭代数随 LR 变化

核心洞察

  • learning_rate 减半时，n_estimators 大约需要翻倍才能达到同等效果
  • 较小的 learning_rate 配合充足的树通常泛化能力更强
  • 在计算预算有限时，中等 learning_rate（0.05~0.1）是性价比最高的选择
  • 始终配合 early_stopping 自动确定最优迭代次数，避免过拟合
  • 公式关系（近似）：$\text{score} \approx f(\text{lr} \times \text{n\_estimators})$，但并非简单线性

正则化对比说明

无正则化：模型自由拟合数据，决策边界可能非常复杂，容易捕获噪声导致过拟合。

L1 正则化（reg_alpha）：在损失函数中添加 $\lambda_1 \sum |w_j|$ 惩罚项。 倾向于将部分特征的贡献压缩为零，起到特征选择的作用。边界更简洁，适合存在无关特征的场景。

L2 正则化（reg_lambda）：在损失函数中添加 $\lambda_2 \sum w_j^2$ 惩罚项。 让所有特征的权重都趋于更小但不为零，使模型更平滑。通常是首选的正则化方式。
