01 — 向量基础

理解向量的几何意义与基本运算，为线性代数打下直觉基础。

→

1. 什么是向量

向量是同时具有大小（模）和方向的量。在二维平面中，一个向量可以用分量 $[x, y]$ 表示。

$$\vec{v} = [v_x,\; v_y], \quad |\vec{v}| = \sqrt{v_x^2 + v_y^2}$$

方向角 $\theta = \text{atan2}(v_y, v_x)$，取值范围为 $(-\pi, \pi]$。

在可视化区域中点击任意位置，创建从原点出发的向量；拖拽箭头端点可以调整向量。

2. 向量加减法

向量加法遵循平行四边形法则：将两个向量首尾相连，对角线即为和向量。

$$\vec{a}+\vec{b} = [a_1+b_1,\; a_2+b_2]$$ $$\vec{a}-\vec{b} = [a_1-b_1,\; a_2-b_2]$$
a = [2, 1]
b = [1, 2]
结果 = [3, 3]

3. 数乘与线性组合

数乘将向量等比缩放：$k > 0$ 同方向拉伸，$k < 0$ 反向翻转，$|k| < 1$ 缩短。

线性组合：任意两个不共线的向量可以张成整个平面。

$$c_1\vec{v_1} + c_2\vec{v_2}$$

4. 点积与夹角

点积衡量两个向量的"对齐程度"，与夹角余弦直接相关。

$$\vec{a}\cdot\vec{b} = a_1 b_1 + a_2 b_2 = |\vec{a}||\vec{b}|\cos\theta$$
  • 点积 > 0：夹角为锐角（方向相近）
  • 点积 = 0：夹角为直角（正交）
  • 点积 < 0：夹角为钝角（方向相反）
a = [2, 1]
b = [1, 2]
a · b = 4
夹角 θ = 36.87°

5. 向量投影

投影是将一个向量分解为沿另一向量方向的分量和垂直分量。

$$\text{proj}_{\vec{b}}\vec{a} = \frac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\vec{b}$$

残差向量 $\vec{a} - \text{proj}_{\vec{b}}\vec{a}$ 与 $\vec{b}$ 垂直。

a = [2, 3]
b = [3, 1]
投影 = [2.7, 0.9]
残差 = [-0.7, 2.1]
标量系数: 0.9
