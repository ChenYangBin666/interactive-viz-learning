模块 07 — Transformer 解码器

解码器是 Transformer 中负责"生成"的核心组件。它通过掩码自注意力防止看到未来信息， 通过交叉注意力关注编码器输出，并以自回归方式逐步生成序列。

◩

1. 掩码自注意力 (Masked Self-Attention)

在解码器中，自注意力必须加上因果掩码（Causal Mask）：每个位置只能关注它自身及之前的位置，不能"偷看"未来的 token。

掩码是一个下三角矩阵：对角线及以下为 1（允许），对角线以上为 0（禁止，用 $-\infty$ 填充使 softmax 输出为 0）。

2. 为什么需要掩码？

训练时，所有 token 并行处理以加速训练。但如果没有掩码，每个 token 可以看到整个序列（包括未来），这是信息泄露。 掩码确保即使并行计算，每个位置也只能看到过去。

编码器 双向注意力

每个 token 可以看到所有其他 token

解码器 单向注意力

每个 token 只能看到自身及之前的 token

关键区别：编码器用于理解输入（双向），解码器用于生成输出（单向）。掩码让解码器在训练时模拟推理时的逐步生成过程。

⇄

3. 交叉注意力 (Cross-Attention)

交叉注意力是解码器独有的机制：Q 来自解码器， K 来自编码器， V 来自编码器。 这让解码器在生成每个 token 时"关注"源序列的相关部分。

4. 完整解码器块

一个完整的解码器块包含 3 个子层（编码器只有 2 个）： 掩码自注意力 → 交叉注意力 → 前馈网络。每个子层都包裹着残差连接 + 层归一化。

解码器块 vs 编码器块：

编码器：自注意力 → Add&Norm → FFN → Add&Norm (2 子层)

解码器：掩码自注意力 → Add&Norm → 交叉注意力 → Add&Norm → FFN → Add&Norm (3 子层)

⟳

5. 自回归生成

推理时，解码器以自回归（Autoregressive）方式生成输出：每一步输入已生成的 token， 运行解码器得到下一个 token 的概率分布，选择概率最高的 token（贪心）或采样，然后将其加入输入继续生成。
