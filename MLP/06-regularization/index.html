过拟合 vs 欠拟合

模型复杂度决定了拟合能力。欠拟合（高偏差）：模型太简单，无法捕捉数据规律； 过拟合（高方差）：模型太复杂，记住了噪声而非真实模式。 调整多项式阶数观察变化：$$\hat{y} = w_0 + w_1 x + w_2 x^2 + \cdots + w_d x^d$$

L1 与 L2 正则化

在损失函数中加入权重惩罚项，抑制过大的权重值： $$L = L_{\text{data}} + \lambda \|\mathbf{w}\|_p$$ L1（Lasso，$p=1$）：产生稀疏权重（许多为零）。 L2（Ridge，$p=2$）：使权重均匀缩小但不为零。

Dropout

训练时随机"丢弃"神经元（输出置零），迫使网络不依赖任何单个特征。 每次前向传播使用不同的子网络，等价于训练了大量模型的集成。 测试时使用所有神经元，但输出需要乘以 $(1 - p)$ 进行缩放。

Early Stopping 与 Batch Normalization

Early Stopping：监控验证集损失，当它开始上升时停止训练，防止过拟合。
Batch Normalization：对每层的激活值进行归一化 $\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}$， 使分布更稳定，加速训练并起到轻微正则化效果。
