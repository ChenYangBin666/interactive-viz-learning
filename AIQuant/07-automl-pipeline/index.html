自动特征选择

从 120+ 候选特征中自动筛选最优子集。选择方法对比：

互信息 (Mutual Information)：衡量特征与目标之间的非线性依赖关系。

$$I(X;Y) = \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)}$$

前向选择 (Forward Selection)：逐步添加最能提升模型性能的特征。

$$S_{k+1} = S_k \cup \{\arg\max_{f \notin S_k} \text{Score}(S_k \cup \{f\})\}$$

LASSO 正则化：通过 L1 惩罚自动将不重要的特征系数压缩为零。

$$\min_\beta \|y - X\beta\|_2^2 + \lambda \|\beta\|_1$$

超参数优化

对比网格搜索、随机搜索与贝叶斯优化在超参数空间中的搜索效率。

贝叶斯优化使用高斯过程建模目标函数，通过采集函数决定下一个采样点：

$$\alpha(\mathbf{x}) = \mu(\mathbf{x}) + \kappa \cdot \sigma(\mathbf{x})$$

其中 \(\mu\) 为预测均值，\(\sigma\) 为预测不确定性，\(\kappa\) 控制探索与利用的平衡。
