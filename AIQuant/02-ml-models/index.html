线性模型

Ridge 和 Lasso 回归通过添加正则化项约束系数大小，防止过拟合。在因子选股中，正则化帮助筛选有效因子，抑制噪声因子的影响。

$$\text{Ridge: } \min_\beta \| y - X\beta \|^2 + \lambda \|\beta\|_2^2 \quad\quad \text{Lasso: } \min_\beta \| y - X\beta \|^2 + \lambda \|\beta\|_1$$

模型选择与验证

金融时间序列数据不能使用随机 K-Fold 交叉验证！必须采用时间序列专用的验证方法，避免未来信息泄露（数据窥探偏差）。

⚠ 随机 K-Fold 在时序数据上会导致数据泄露：未来数据被用于训练，模型回测表现虚高！

过拟合诊断

过拟合是量化模型的大敌：模型在训练集上表现优异，但在新数据上失效。通过学习曲线和复杂度曲线可以及早发现过拟合信号。
