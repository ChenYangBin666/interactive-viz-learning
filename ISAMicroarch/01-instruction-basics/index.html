什么是指令

一条指令就像一句简短的命令，告诉处理器"做什么"和"对谁做"。就像人类语言中的 动词 + 宾语，指令由 操作码（做什么）和 操作数（对谁做）组成。

人类语言
把 A 和 B 加起来，放到 C
↔
汇编指令
add x1, x2, x3

点击下方每个字段，查看详细解释

add

操作码 (Opcode)

指令的"动词"，决定处理器执行什么操作。add 表示加法运算。不同的操作码对应不同的运算：加、减、与、或、跳转等。

x1

目标寄存器 (rd)

运算结果存放的位置。x1 是 RISC-V 的第 1 号通用寄存器。相当于"把答案写在哪"。

x2

源寄存器1 (rs1)

第一个操作数的来源。x2 中存放的值将参与运算。相当于"加法的第一个数"。

x3

源寄存器2 (rs2)

第二个操作数的来源。x3 中存放的值将与 rs1 一起参与运算。相当于"加法的第二个数"。

指令格式对比

不同的计算机架构使用不同数量的操作数。操作数越多，指令越灵活但也越长；操作数越少，指令越短但需要更多条指令完成同样的计算。

三地址格式

每条指令指定两个源操作数和一个目标操作数。最灵活，一条指令就能完成一个完整运算。RISC-V、ARM、MIPS 使用此格式。

寻址模式

寻址模式决定了指令如何找到操作数。不同的寻址模式适用于不同的场景 —— 从最简单的立即数到复杂的间接寻址。

立即数寻址

操作数直接编码在指令中。例如 addi x1, x0, 42 中的 42 就是立即数。

指令执行周期

每条指令在处理器中经历 5 个阶段：取指 (IF)、译码 (ID)、执行 (EX)、访存 (MEM)、写回 (WB)。点击步进按钮，逐步观察数据在硬件模块之间的流动。
