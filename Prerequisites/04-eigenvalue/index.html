01

什么是特征值/特征向量

对于方阵 $A$，如果存在非零向量 $\vec{v}$ 和标量 $\lambda$，使得 $A\vec{v} = \lambda\vec{v}$，则 $\lambda$ 为特征值，$\vec{v}$ 为特征向量。 特征向量在矩阵变换下只改变长度，不改变方向（或反向）。

大多数向量经过矩阵变换后会同时改变方向和长度。特征向量是特殊的——它们只会被拉伸或压缩，始终保持在原来的直线上。

02

特征方程

从 $A\vec{v} = \lambda\vec{v}$ 出发，移项得 $(A - \lambda I)\vec{v} = \vec{0}$。 要有非零解，需要 $\det(A - \lambda I) = 0$，这就是特征方程。 对于 $2 \times 2$ 矩阵，展开得到 $\lambda^2 - \text{tr}(A)\lambda + \det(A) = 0$。

03

几何直觉

特征值的大小和符号决定了变换的几何效果。理解这些情况有助于直观把握矩阵变换的本质。

观察：灰色箭头是原始向量，红色箭头是变换后的位置。 绿色/橙色箭头是特征向量——注意它们始终保持在同一条直线上。

04

PCA 直觉预览

PCA（主成分分析）的核心思想：对数据协方差矩阵做特征值分解。 特征向量 = 主成分方向，特征值 = 该方向上的方差。这是降维和数据分析的基础工具。
