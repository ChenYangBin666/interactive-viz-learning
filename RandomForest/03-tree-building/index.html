CART 算法总结

CART（Classification and Regression Trees）是最经典的决策树算法之一，生成二叉树结构。

分类树（Classification）

使用基尼不纯度选择最优分裂：

$$Gini(D) = 1 - \sum_{k=1}^{K} p_k^2$$
$$\Delta Gini = Gini(D) - \frac{|D_L|}{|D|}Gini(D_L) - \frac{|D_R|}{|D|}Gini(D_R)$$
  • 选择使 $\Delta Gini$ 最大的特征和阈值
  • 将数据按阈值分为左右子集
  • 递归地在子集上重复步骤 1-2
  • 满足停止条件时创建叶节点
  • 叶节点预测值 = 多数类别

回归树（Regression）

使用方差缩减（MSE）选择最优分裂：

$$MSE(D) = \frac{1}{|D|}\sum_{i \in D}(y_i - \bar{y})^2$$
$$\Delta MSE = MSE(D) - \frac{|D_L|}{|D|}MSE(D_L) - \frac{|D_R|}{|D|}MSE(D_R)$$
  • 选择使 $\Delta MSE$ 最大的特征和阈值
  • 将数据按阈值分为左右子集
  • 递归地在子集上重复步骤 1-2
  • 满足停止条件时创建叶节点
  • 叶节点预测值 = 子集均值 $\bar{y}$

伪代码

function BuildTree(D, depth): if 停止条件满足(D, depth): return 创建叶节点(D) bestFeature, bestThreshold ← FindBestSplit(D) if bestGain ≤ 0: return 创建叶节点(D) D_L ← {x ∈ D | x[bestFeature] ≤ bestThreshold} D_R ← {x ∈ D | x[bestFeature] > bestThreshold} node.left ← BuildTree(D_L, depth + 1) node.right ← BuildTree(D_R, depth + 1) return node
