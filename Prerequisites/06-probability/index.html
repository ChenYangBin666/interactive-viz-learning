概率基础

概率衡量事件发生的可能性：

$$P(\text{事件}) = \frac{\text{有利结果数}}{\text{总结果数}}$$

当试验次数越多，频率就越接近理论概率——这就是大数定律。

Softmax 函数

将任意实数向量（logits）转换为概率分布：

$$\text{softmax}(z_i) = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$$

交叉熵

衡量预测分布 $q$ 与真实分布 $p$ 之间的差异：

$$H(p, q) = -\sum_i p_i \log q_i$$

当 $q = p$ 时，交叉熵最小（等于 $p$ 的熵）。$q$ 偏离 $p$ 越远，损失越大。

这是神经网络分类任务中最常用的损失函数。

KL 散度与信息论

KL 散度衡量分布 $Q$ 偏离 $P$ 的程度：

$$D_{KL}(P \| Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)}$$

性质：$D_{KL} \ge 0$，当且仅当 $P = Q$ 时等于 0。

熵衡量分布的不确定性：$H(P) = -\sum_i P(i) \log_2 P(i)$

低熵 = 确定（尖锐），高熵 = 不确定（均匀）。
