03 - 消息传递机制

Message Passing -- GNN 的核心计算范式

消息传递是几乎所有 GNN 的共同基础。理解它，就等于理解了 GCN、GAT、GraphSAGE 的底层逻辑。

消息传递的通用公式

$$h_v^{(l+1)} = \text{UPDATE}\Big(h_v^{(l)},\; \text{AGG}\big(\{\text{MSG}(h_u^{(l)}) : u \in \mathcal{N}(v)\}\big)\Big)$$

多轮传递 = 感受野扩大

每多传递一轮，节点能"看到"更远的邻居。$k$ 轮传递后，节点的感受野覆盖 $k$-hop 邻域。

$$\text{第 } k \text{ 轮后，节点 } v \text{ 的感受野} = \{u : d(u,v) \leq k\}$$

1-hop 邻域

直觉：1 轮 = 只看直接邻居。2 轮 = 邻居的邻居也能影响你。 这就像社交网络里"朋友的朋友"。但层数太多会导致过平滑问题。

4

矩阵视角 -- 一次传递的完整计算

消息传递可以用一个优雅的矩阵公式表达：

$$H^{(l+1)} = \sigma\!\Big(\hat{A}\, H^{(l)}\, W^{(l)}\Big)$$

$\hat{A} = \tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}$ 归一化邻接矩阵， $\tilde{A} = A + I$ 加自环， $W^{(l)}$ 可学习权重， $\sigma$ 激活函数

准备 逐步展示矩阵乘法过程

关键洞察：$\hat{A} \times H$ 就是"邻居聚合"的矩阵写法 -- 第 $i$ 行与 $H$ 相乘， 相当于节点 $i$ 收集邻居特征的加权平均。乘以 $W$ 是线性变换，$\sigma$ 引入非线性。
