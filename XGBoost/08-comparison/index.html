Bagging vs Boosting 原理对比

两种集成学习范式如何组合弱学习器：Bagging 独立组合降方差，Boosting 逐步纠错降偏差。

Bagging 路径
Boosting 路径

Bagging 核心：从原始数据有放回抽样 → 训练多棵独立树 → 平均/投票。
效果：降低方差，对噪声更鲁棒。

Boosting 核心：顺序构建，每棵树拟合前一轮残差 → 累加预测。
效果：降低偏差，逐步逼近真实函数。

3

GBDT vs XGBoost

XGBoost 在传统梯度提升树(GBDT)基础上做了哪些关键改进？

GBDT (传统)

  • G一阶梯度（梯度下降）
  • -无二阶梯度
  • -无正则化项
  • -无列采样
  • -无稀疏感知
  • -未优化工程实现

XGBoost (增强)

  • G一阶梯度
  • H 二阶梯度（牛顿法） 关键
  • Ω 正则化项 \Omega(f) = \gamma T + \frac{1}{2}\lambda\|w\|^2 关键
  • C列采样（类似随机森林思想）
  • S稀疏感知（自动处理缺失值）
  • E工程优化（缓存、并行分裂、分位数近似）

二阶 vs 一阶：权重估计的精度

一阶梯度下降用直线近似损失函数来找最优权重，而二阶牛顿法用抛物线近似，一步就能更接近最优点。

一阶：线性近似（需多步）
二阶：抛物线近似（一步到位）
