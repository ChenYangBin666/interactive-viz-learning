Leaf-wise 生长策略

LightGBM 的核心创新之一：抛弃传统 Level-wise（逐层）生长方式，改用 Leaf-wise（最优叶子优先）策略。 每一步都选择全局增益最大的叶子节点进行分裂，以更少的叶子数量达到更低的损失值。

$$\text{Leaf-wise: } \quad \text{split leaf } = \arg\max_{l \in \mathcal{L}} \; \text{Gain}(l)$$

其中 \(\mathcal{L}\) 是当前所有叶子节点的集合，Gain 为该叶子最佳分裂点的增益。

📊

Level-wise 生长（逐层）

XGBoost 风格

过拟合风险

Leaf-wise 可能在一侧生长很深，导致对训练数据过拟合。增大 num_leaves 时， 验证集损失可能反弹。通过 max_depth 限制可以有效缓解。

num_leaves 与 max_depth 关系

对于一棵完全二叉树，深度为 \(d\) 时最多有 \(2^d\) 个叶子。 LightGBM 推荐 num_leaves < 2^max_depth，以避免 leaf-wise 生长产生过深的树。

$$\text{num\_leaves} \leq 2^{\text{max\_depth}}$$

当 num_leaves = 2^max_depth 时等价于完全二叉树；更小的 num_leaves 意味着树更稀疏，不会填满每一层。
