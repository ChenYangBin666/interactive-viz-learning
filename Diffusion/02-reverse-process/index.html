为什么能逆转？

直觉理解

前向扩散过程每一步只加入少量噪声（\(\beta_t\) 很小），因此逆向条件分布 \(q(\mathbf{x}_{t-1}|\mathbf{x}_t)\) 也近似为高斯分布。这意味着我们可以用一个神经网络 来学习这个逆向分布的参数。

$$p_\theta(\mathbf{x}_{t-1}|\mathbf{x}_t) = \mathcal{N}\!\bigl(\mathbf{x}_{t-1};\, \boldsymbol{\mu}_\theta(\mathbf{x}_t, t),\, \boldsymbol{\Sigma}_\theta(\mathbf{x}_t, t)\bigr)$$

核心直觉：当每步噪声足够小时，逆向过程和前向过程具有相同的函数形式——都是高斯分布。我们只需要学习均值和方差即可。

后验分布推导

数学推导

虽然 \(q(\mathbf{x}_{t-1}|\mathbf{x}_t)\) 不可解析求解，但如果已知 \(\mathbf{x}_0\)， 后验 \(q(\mathbf{x}_{t-1}|\mathbf{x}_t, \mathbf{x}_0)\) 是可以精确计算的高斯分布。

步骤一：利用贝叶斯公式

$$q(\mathbf{x}_{t-1}|\mathbf{x}_t, \mathbf{x}_0) = \frac{q(\mathbf{x}_t|\mathbf{x}_{t-1}, \mathbf{x}_0)\, q(\mathbf{x}_{t-1}|\mathbf{x}_0)}{q(\mathbf{x}_t|\mathbf{x}_0)}$$

步骤二：代入高斯分布的表达式

每个条件分布都是高斯分布：

$$q(\mathbf{x}_t|\mathbf{x}_{t-1}) = \mathcal{N}(\mathbf{x}_t; \sqrt{1-\beta_t}\,\mathbf{x}_{t-1}, \beta_t \mathbf{I})$$

$$q(\mathbf{x}_{t-1}|\mathbf{x}_0) = \mathcal{N}(\mathbf{x}_{t-1}; \sqrt{\bar\alpha_{t-1}}\,\mathbf{x}_0, (1-\bar\alpha_{t-1})\mathbf{I})$$

步骤三：配方得到后验参数

$$q(\mathbf{x}_{t-1}|\mathbf{x}_t, \mathbf{x}_0) = \mathcal{N}(\mathbf{x}_{t-1};\, \tilde{\boldsymbol{\mu}}_t,\, \tilde\beta_t \mathbf{I})$$

$$\tilde{\boldsymbol{\mu}}_t = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,\mathbf{x}_0 + \frac{\sqrt{\alpha_t}\,(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,\mathbf{x}_t$$
$$\tilde\beta_t = \frac{(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,\beta_t$$

噪声预测 vs x₀ 预测

对比分析

模型有两种等价的预测目标。左侧：模型预测噪声 \(\boldsymbol{\epsilon}\)，然后通过公式计算 \(\mathbf{x}_{t-1}\)。右侧：模型直接预测 \(\mathbf{x}_0\)，再反推 \(\mathbf{x}_{t-1}\)。

噪声预测参数化

$$\boldsymbol{\mu}_\theta(\mathbf{x}_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(\mathbf{x}_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)\right)$$

x₀ 预测参数化

$$\hat{\mathbf{x}}_0 = f_\theta(\mathbf{x}_t, t), \quad \boldsymbol{\mu}_\theta = \frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}\,\hat{\mathbf{x}}_0 + \frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,\mathbf{x}_t$$

两种参数化在数学上完全等价——因为 \(\mathbf{x}_0 = \frac{1}{\sqrt{\bar\alpha_t}}(\mathbf{x}_t - \sqrt{1-\bar\alpha_t}\,\boldsymbol{\epsilon})\)。

训练目标

可视化

DDPM 的简化训练目标非常优雅：在每个训练步中，随机采样时间步 \(t\)，添加噪声得到 \(\mathbf{x}_t\)，然后让模型预测添加的噪声。损失函数就是预测噪声与真实噪声之间的均方误差。

$$L_{\text{simple}} = \mathbb{E}_{t, \mathbf{x}_0, \boldsymbol{\epsilon}}\left[\left\| \boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta\!\left(\sqrt{\bar\alpha_t}\,\mathbf{x}_0 + \sqrt{1-\bar\alpha_t}\,\boldsymbol{\epsilon},\, t\right) \right\|^2\right]$$

训练循环：采样 t → 采样噪声 ε → 构造 x_t → 模型预测 ε_θ → 计算 MSE → 梯度更新
