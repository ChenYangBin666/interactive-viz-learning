异常检测

在正常收益率序列中注入异常点，比较 Z-score、Isolation Forest 和 Autoencoder 三种检测方法的效果。 异常交易检测是风控系统的第一道防线，能够在市场操纵、闪崩等事件中提前发出预警。

$$\text{Z-score} = \frac{x - \mu}{\sigma}, \quad \text{异常条件:} |z| > \theta$$

$$\text{Isolation Forest: } s(x, n) = 2^{-\frac{E[h(x)]}{c(n)}}, \quad \text{Autoencoder: } L = \|x - \hat{x}\|^2$$

尾部风险预测

比较传统 VaR（历史模拟法）与 ML 增强 VaR（条件特征），观察危机期间的表现差异。 传统 VaR 假设收益率服从正态分布，在尾部事件中严重低估风险；ML 增强 VaR 利用波动率聚集、趋势动量等条件特征动态调整风险估计。

$$\text{VaR}_\alpha = -\inf\{x : P(X \le x) \ge \alpha\}, \quad \text{CVaR}_\alpha = E[X | X \le -\text{VaR}_\alpha]$$

市场 Regime 检测

使用隐马尔可夫模型 (HMM) 检测市场状态：牛市、熊市、高波动。不同 regime 以背景色区分。 Regime 检测帮助策略根据市场状态动态调整仓位和风险敞口，在高波动期降低杠杆，在牛市中增加持仓。

$$P(S_t | S_{t-1}) = A_{ij}, \quad P(X_t | S_t = k) = \mathcal{N}(\mu_k, \sigma_k^2)$$

信用风险评分

比较 Logistic 回归、XGBoost 和神经网络在违约预测中的表现。调整借款人特征观察评分变化。 信用评分模型是银行风控的核心，通过对借款人多维特征的综合评估来预测违约概率。

$$P(\text{default}) = \sigma(\beta_0 + \sum_i \beta_i x_i), \quad \sigma(z) = \frac{1}{1+e^{-z}}$$

$$\text{AUC} = \int_0^1 \text{TPR}(t)\,dt = P(\hat{y}_{+} > \hat{y}_{-})$$

实时风控系统
