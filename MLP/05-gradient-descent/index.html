梯度下降 Gradient Descent

梯度下降是训练神经网络的基石。本模块通过四个交互式可视化，帮助你建立对梯度下降的直觉理解——从最基本的参数更新规则，到 SGD 变体、现代优化器对比，再到学习率调度策略。

1

梯度下降直觉

梯度下降是深度学习中最核心的优化方法。想象你站在山坡上，闭着眼想要走到最低点——你唯一能做的就是感受脚下哪个方向最陡，然后朝相反方向迈一步。这个过程不断重复，直到到达（或接近）最低点。

学习率 $\eta$ 决定了每一步的步幅：太大容易越过最低点来回震荡（overshoot），太小则需要非常多步才能到达。选择合适的学习率是训练神经网络的关键技巧之一。

参数更新公式：

$$\theta_{t+1} = \theta_t - \eta \nabla L(\theta_t)$$

其中 $\eta$ 为学习率，$\nabla L$ 为损失函数的梯度

试一试：点击等高线图上的任意位置放置小球，观察它沿负梯度方向"滚下山"的轨迹。将学习率调大（>0.2）会看到超调；调小（<0.01）则收敛极慢。

SGD vs Mini-batch vs Batch

在实际训练中，我们不会每次都用全部数据计算梯度。根据每次使用的样本数量，梯度下降分为三种变体：

Batch GD（全量）：使用所有样本，梯度准确、路径平滑，但计算代价高。

SGD（随机）：每次只用 1 个样本，梯度噪声大、路径锯齿，但每步计算快。

Mini-batch：折中方案，用一小批样本（如 32），兼顾速度与稳定性。

Batch Gradient Descent

每步使用全部 N 个样本计算梯度。方向精确，收敛路径最平滑。但每步计算量 O(N)，大数据集下极慢。无法在线学习。

Stochastic GD (SGD)

每步随机取 1 个样本。计算快，能实时更新（在线学习）。梯度方差大，路径锯齿严重，但噪声可帮助逃出尖锐的局部极小值。

Mini-batch GD

每步取 B 个样本（常见 B=32, 64, 128）。兼顾效率与稳定性，GPU 并行友好。实际训练中最常用的策略。

梯度方差与 batch size 的关系：

$$\text{Var}[\nabla L_B] = \frac{\sigma^2}{B}$$

batch size $B$ 越大，梯度估计的方差越小，轨迹越平滑

优化器对比

原始 SGD 存在收敛慢、容易被困在鞍点等问题。研究者提出了一系列改进优化算法：加入动量（Momentum）利用历史梯度加速收敛、自适应学习率（RMSProp）根据参数特点调整步幅、以及两者的结合（Adam）。

鞍点测试：勾选"鞍点曲面"，观察 SGD 几乎停在原地（梯度趋近零），而 Momentum 凭借惯性冲过鞍点，Adam 也能快速逃离。

SGD

$$\theta \leftarrow \theta - \eta\,g$$

最朴素的梯度下降。每步仅依赖当前梯度，没有"记忆"。

SGD + Momentum

$$v \leftarrow \beta v + g$$
$$\theta \leftarrow \theta - \eta\,v$$

引入动量项 $v$（类似惯性），加速沿一致方向的更新，抑制震荡。$\beta$ 通常取 0.9。

RMSProp

$$s \leftarrow \beta s + (1-\beta)\,g^2$$
$$\theta \leftarrow \theta - \frac{\eta}{\sqrt{s}+\epsilon}\,g$$

用梯度平方的移动平均自适应调整每个参数的学习率。梯度大的方向步幅自动减小。

Adam

$$m \leftarrow \beta_1 m + (1-\beta_1)\,g$$
$$v \leftarrow \beta_2 v + (1-\beta_2)\,g^2$$
$$\theta \leftarrow \theta - \frac{\eta\,\hat{m}}{\sqrt{\hat{v}}+\epsilon}$$

结合 Momentum 的一阶矩估计和 RMSProp 的二阶矩估计，附带偏差校正。是目前最常用的优化器。

优化器 自适应学习率 动量 推荐场景 超参数
SGD 否否 简单凸优化问题 $\eta$
SGD+Momentum 否是 CNN 训练（配合调度） $\eta, \beta$
RMSProp 是否 RNN、非平稳目标 $\eta, \beta, \epsilon$
Adam 是是 通用默认选择 $\eta, \beta_1, \beta_2, \epsilon$

实践建议：不确定用什么优化器时，先试 Adam（lr=3e-4）。若追求最佳泛化性能，SGD+Momentum+调度 常常能超过 Adam，但需要更仔细地调参。

学习率调度

训练全程使用固定学习率并非最优策略。合理的学习率调度（Learning Rate Scheduling）能让模型在训练前期以较大步幅快速接近最优区域，后期以较小步幅精细调整，从而显著提升最终性能和训练稳定性。

点击"全部对比"可以同时查看四种策略在相同条件下的 LR 曲线和损失曲线。

恒定学习率：整个训练过程学习率保持不变。简单但可能不是最优的——前期可能不够快，后期可能过大导致震荡。

经验法则：Cosine Annealing 和 Warmup + Decay 是目前最流行的调度策略。Warmup 让初始不稳定的大梯度不至于破坏权重，之后再逐步降低学习率做精细搜索。

阶梯衰减公式：

$$\eta_t = \eta_0 \cdot \gamma^{\lfloor t / T_{step} \rfloor}$$

每隔 $T_{step}$ 个 epoch 衰减一次

余弦退火公式：

$$\eta_t = \eta_{min} + \frac{\eta_0 - \eta_{min}}{2}\left(1 + \cos\frac{\pi t}{T}\right)$$

平滑地从 $\eta_0$ 降至 $\eta_{min}$

线性 Warmup：

$$\eta_t = \eta_0 \cdot \frac{t}{T_{warm}}, \quad t < T_{warm}$$

前 $T_{warm}$ 步线性增大

Warmup + 线性衰减：

$$\eta_t = \eta_0 \cdot \max\!\left(0,\; \frac{T - t}{T - T_{warm}}\right)$$

Warmup 之后线性衰减到 0

注意：学习率调度与优化器的选择是正交的——你可以在 Adam 上使用 Cosine Annealing，也可以在 SGD+Momentum 上使用 Warmup。两者配合使用效果更佳。

调度策略优点缺点典型应用
恒定简单无需调参后期易震荡快速实验
阶梯衰减经典有效衰减时机需手动设定ResNet, VGG
余弦退火平滑、无需手动节点对周期长度敏感Vision Transformer
Warmup+衰减稳定初始化阶段多一个超参数BERT, GPT
